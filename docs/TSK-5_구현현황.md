# TSK-5 파일 필터 드라이버 구현 현황

## 현재 구현된 내용

- `UF_FileFilterFactory.sys`: 감시 폴더와 보호 폴더 정책, 파일 접근 이벤트, 보호 폴더 접근 차단을 구현했습니다.
- 보호 폴더별 허용 프로세스를 지정하고 읽기·쓰기 권한을 독립적으로 설정할 수 있습니다.
- 허용 프로세스별로 정규화된 전체 경로 또는 실행 파일 이름 비교 방식을 선택할 수 있습니다.
- 허용 프로세스별 코드 서명 확인 여부를 설정할 수 있으며, 서명 확인 시 인증서 SHA-256 식별 정보를 사용합니다.
- PID와 프로세스 생성 시각을 함께 확인하여 PID 재사용을 방지하고 정책 세대가 바뀌면 신뢰 캐시를 초기화합니다.
- `uf_fltwarp.dll`: C ABI로 통신 포트 연결, V2 정책 전송, 이벤트 수신, 프로세스 신뢰 응답, 서명 정보 조회를 제공합니다.
- 드라이버 요청은 별도 작업에서 수행하며 5초 안에 응답하지 않으면 `ERROR_TIMEOUT`을 반환합니다.
- WPF 개발 UI: 파일 제어 탭에서 폴더와 허용 프로세스 정책을 설정하고 파일 이벤트 로그를 확인할 수 있습니다.
- UI에서 파일 드라이버 설치·제거·연결·연결 해제와 정책 적용·초기화를 수행할 수 있습니다.
- UI와 DLL은 실행 위치의 `logs` 폴더에 단계별 진단 로그를 남깁니다.
- `UF_FileFilterTest.exe`에 ABI 및 정책 입력 자체 점검을 포함했습니다.

## 빌드 및 확인

- Debug x64와 Release x64에서 드라이버, 통신 DLL, UI, 테스트 프로그램을 빌드했습니다.
- 드라이버 시험 서명과 카탈로그 생성의 Signability 검사는 오류 없이 완료되었습니다.
- 현재 개발 환경의 WDK에는 `x86\InfVerif.dll`이 없어 패키지 검증 단계는 별도 확인이 필요합니다.
- 커널 드라이버는 시험용 VM에서만 설치하고 확인합니다.

## 아직 구현하지 않은 범위

- `UF_ProcessFilterFactory.sys`와 `uf_procwarp.dll`은 다음 작업으로 남아 있습니다.
- 프로세스 제어 탭의 실제 기능과 배포용 서명·설치 자동화는 통합 단계에서 진행합니다.
